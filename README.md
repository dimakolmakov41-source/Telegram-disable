# Telegram Pause

Небольшое Android-приложение на Kotlin с таймером добровольной паузы.

## Возможности
- Таймер на 5, 15 или 30 минут.
- Запуск, приостановка и сброс таймера.
- Экранный статус паузы.

## Важно
Приложение **не блокирует Telegram**, не вмешивается в другие приложения, не удаляет их и не меняет системные настройки. Это простой таймер-памятка для добровольного перерыва.

## Сборка
Открой проект в Android Studio или совместимой Android IDE и собери задачу:

```
:app:assembleDebug
```

Также GitHub Actions автоматически собирает APK при push в ветку `main`. Готовый APK будет доступен во вкладке Actions как артефакт `Telegram-Pause-debug`.

- Язык: Kotlin
- Минимальная версия Android: 6.0 (API 23)
- Compile SDK: 35
